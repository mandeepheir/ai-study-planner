from pathlib import Path

readme = r"""# AI Study Planner

A responsive study-planning web application built with Angular and Firebase to help students organize tasks, track their progress, and decide what to focus on next.

🌐 **Live Demo:** https://ai-study-planner-11f5f.web.app

## Features

- **Study task management** — create and manage study tasks.
- **Authentication** — sign in using Firebase Authentication.
- **Cloud data storage** — store user data with Cloud Firestore.
- **User-specific security** — Firestore security rules help restrict access to each user's data.
- **Dashboard** — review study activity and task status.
- **Progress analytics** — view progress by category, with charts powered by ApexCharts.
- **Study recommendations** — rule-based suggestions to help prioritize work based on task categories and deadlines.
- **Daily planning and study sessions** — organize study work into manageable sessions.
- **Search and filtering** — find tasks more easily.
- **Dark mode** — switch to a darker interface.
- **Responsive interface** — designed to work across different screen sizes.
- **LocalStorage support** — browser storage is used for supported local persistence or backup behavior.

> Note: The study recommendations are rule-based in the current version; they are not generated by a large language model.

## Tech Stack

- **Frontend:** Angular, TypeScript, HTML, CSS
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore
- **Charts:** ApexCharts
- **Hosting:** Firebase Hosting

## Application Overview

AI Study Planner brings task management, progress tracking, and study recommendations together in one interface. The goal is to make it easier to plan study sessions, monitor completion, and identify which tasks need attention.

## Getting Started

### Prerequisites

- Node.js and npm
- Angular CLI compatible with the project's Angular version
- A Firebase project if you want to connect the application to your own Firebase services

### Install dependencies

Clone the repository and enter the project directory:

```bash
git clone https://github.com/mandeepheir/ai-study-planner.git
cd ai-study-planner
npm install
```

### Configure Firebase

If running your own copy, configure the Firebase settings for your Firebase project in the application's environment/configuration files. Enable Firebase Authentication and create a Cloud Firestore database. Review and apply appropriate Firestore security rules before using real user data.

**Do not commit private credentials, service-account keys, or secrets to GitHub.**

### Run locally

```bash
ng serve
```

Open `http://localhost:4200/` in your browser.

### Build for production

```bash
ng build
```

The generated build output will be in the directory configured by the Angular build setup.

## Security Notes

- Firestore rules should enforce user-specific access on the server side; hiding data in the UI is not sufficient.
- Use your own Firebase configuration when deploying your own instance.
- Never commit secrets or service-account credentials.
- Review Firebase Authentication and Firestore rules before using the application with sensitive information.

## Future Improvements

- Add an optional generative-AI integration for personalized study plans.
- Improve study-session insights and progress summaries.
- Add reminders and richer scheduling options.
- Expand accessibility and automated testing.
